kitutilpy é um simples módulo para reduzir o número de importações 

kitutilpy.pausar(number)
faz uma pausa
kitutilpy.limbarConsole() 
limpa o console
kitutilpy.sortear(lista)
sortea um item de uma lista
kitutilpy.tempoAgora()
mostra horario e data naquele momento
kitutilpy.linkWeb(url)
abre o link da web
kitutilpy.ano(Ano)
mostra o calendário do ano desejado
kitutilpy.mesAno(ANO,mes)
mostra o mês daquele ano
